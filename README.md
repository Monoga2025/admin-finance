# admin-finance

Administration and personal-finance workspace of Monoga OS — the part of the system that keeps the business side organized.

## What is here

| File | Purpose |
|---|---|
| `06_ADMIN_Y_FINANZAS.md` | Index note of the admin area inside the Monoga OS knowledge base. |
| `TRAMITE_CAMBIO_NOMBRE_CCB.md` | Step-by-step runbook for renaming a commercial establishment at the Bucaramanga Chamber of Commerce (LOOVO → GRUPO MONOGA), including the filled request letter template. |

## What is intentionally not published

Real income/expense spreadsheets, family documents and personal media stay private. Identification numbers and registration numbers in the runbook are redacted.

## Why it is in a portfolio

It shows how I document bureaucratic and financial processes as repeatable runbooks that an agent (or a person) can follow.
